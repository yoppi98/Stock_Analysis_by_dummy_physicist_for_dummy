# Stock Analysis by a Dummy Physicist for Dummies

## About This Project

This is my first learning project focused on understanding the basics of the stock market and stock price analysis using Python.

As a physics Ph.D. student with little background in finance, I started this project to learn how the stock market works and explore how Python can be used to analyze financial data.

The main purpose of this repository is **personal learning and practice**, rather than developing a professional trading strategy.

## Main Reference

This project primarily follows the Japanese book:

**Pythonでできる！ 株価データ分析**
- **Author:** 片渕彼富
- **Consultant Editor:** 山田祥寛

Most of the concepts and analysis methods introduced in this repository are based on this book, with some additional experiments and modifications as part of my learning process.

## Disclaimer

This repository is intended solely for educational purposes. The code and analysis are part of my learning process and should not be considered financial or investment advice.
